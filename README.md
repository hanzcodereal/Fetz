<h1 align="center">Fetz</h1>

Fetz adalah aplikasi Android untuk mengunduh video, foto, dan audio dari berbagai platform, dengan alat media bawaan. Semua proses berjalan di perangkat.

## Build APK (GitHub Actions)

1. Upload proyek ini ke repository GitHub.
2. Buka tab **Actions** > **Build APK Release** > **Run workflow** (dijalankan manual, tidak otomatis).
3. Setelah selesai, unduh APK dari bagian **Artifacts** (`Fetz-v1.0.0-APK`).

Build yang dihasilkan adalah **release** (bukan debug) dan sudah ditandatangani dengan keystore yang dibuat otomatis oleh workflow.
